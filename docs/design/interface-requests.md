# Interface requests

Agents write their requests in `docs/design/requests/<task>.md` (one file per task, so merges do not conflict) when they need a change to a shared interface (`foundry_core`, `foundry_content` schema, the public `foundry_sim::Simulation` API). The lead agent decides and makes the change.

Format:

```
## <date> <agent task> — <short title>
What you need, why, and the stub you use until it exists.
```
